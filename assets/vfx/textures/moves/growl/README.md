# Growl Texture Slots

Place move-specific growl textures here.

Suggested first texture:

- `growl_cone_line.png` (single linear fuzzy streak texture)

Recommended look:

- Narrow horizontal line with soft noisy edges
- Bright center, feathered alpha falloff
- Warm red/orange tint-safe grayscale alpha

Recommended size:

- `256x64` or `512x128`
