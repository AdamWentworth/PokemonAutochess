# Historical Route 1 compositions

These one-time scripts reproduce the Blender experiments that led to the
approved south entrance. Daily authoring uses the saved `.blend` and
`tools/environment/blender/arena_pilot.py`; it never reruns these recipes.

The historical `--bridge-root` for these recipes is the research checkout's
`tools/lgpe_blender_bridge`, which retains the freeform generators and canonical
reference importer. Preserve the pass 1-10 `.blend` checkpoints in the private
asset depot. The old composition JSON files remain under `config/environment`
so existing checkpoints and recipe arguments continue to resolve.

For current editing, export, validation, and recovery, see
[the arena runbook](../../../../docs/BLENDER_ARENA_PILOT.md).
